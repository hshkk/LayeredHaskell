## Problem Statement

Our goal is to create a layered implementation of a small Haskell-esque functional language.
Elm and Haskell can be somewhat vexing due to complicated error messages (especially Haskell) incurred by complex features and language-specific idiosyncrasies.
This can make the transition from imperative programming quite jarring and frustrating.
By introducing language levels, we can provide a systematic way to progressively introduce language features without overwhelming students.
Moreover, these levels can meaningfully serve as laboratories for programming language research, as complex features are stripped away.
